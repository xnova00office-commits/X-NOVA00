// プライバシーポリシー・個人情報保護方針

X-NOVA00 勤怠管理システム プライバシーポリシー

X-NOVA00（以下「当方」）は、提供する勤怠管理システム等のサービスにおいて、ユーザーおよび利用企業のプライバシーを尊重し、個人情報および関連データの保護に努めます。

1. 収集する情報およびデータの範囲

当方のアプリケーション（X-NOVA00 勤怠管理システム）および関連サービスでは、サービスの提供および運営のために以下の情報を取得・処理します。

  • Googleアカウント情報に関する事項：当システムの打刻機能および処理において、Googleアカウントの氏名やメールアドレスをアプリ側で取得・保存・利用する処理は行っておりません。
  • 本人確認およびスタッフ認証の仕組み：当システムの打刻における本人確認は、Googleアカウントの認証ではなく、管理者によって事前に「社員登録シート」に登録されたスタッフ名と、打刻時に使用する暗証番号（PIN）の照合によって行われます。
  • Googleスプレッドシートデータ：システムが稼働するために必要なスプレッドシート内の勤怠データ、社員登録データ、およびシステム設定値へのアクセスと読み書きを行います。
  • 従業員・スタッフ情報：社員登録シートに登録される社員情報（スタッフ名、暗証番号/PIN等）が含まれます。
  • 打刻記録データ：打刻システムを通じて送信される情報であり、スプレッドシートの打刻記録シートに以下の列構成で正確に保存されます。
    • Timestamp（打刻日時）
    • Name（スタッフ名：社員登録シートから引き当てられた名称）
    • Type（打刻種別：出勤・退勤・休憩等）
    • Location（打刻拠点名）
    • Latitude（打刻時の位置情報の緯度）
    • Longitude（打刻時の位置情報の経度）
  • お問い合わせ情報：お問い合わせフォームや直接のメール送信を通じてユーザーからご提供いただくお名前、メールアドレス、お問い合わせ内容等の情報です。

2. データの利用目的

当方がアクセスおよび取得したデータ（スプレッドシートデータおよび打刻関連情報）は、以下の目的の範囲内でのみ利用・処理されます。

  • X-NOVA00勤怠管理システムのコア機能（スマートフォン・NFC等を用いた出退勤打刻、勤務時間の自動計算、修正申請・承認、月別集計等）の正確かつ円滑な実行。
  • スタッフ登録シートに基づく本人確認、管理、およびカスタマーサポート対応。
  • システムのセキュリティ確保、不正利用の防止、および動作安定性の維持。

※Google APIから取得したデータの利用および他アプリへの転送は、Google API サービス ユーザー データ ポリシー（限定使用要件を含む）に厳格に準拠します。

3. 第三者へのデータ共有・提供

当方は、以下の場合を除き、ユーザーの事前の同意なく取得した個人情報や関連データを第三者に提供、販売、開示することはありません。

  • 法令に基づく公的機関からの正式な開示請求等、法的義務を果たすために必要な場合。
  • 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき。
  • 決済代行サービス（Paddle等）やインフラストラクチャ等の業務委託先において、本サービスの提供・決済処理に必要な最小限の範囲でデータが取り扱われる場合。

4. データの保存場所・保護・セキュリティ対策

ユーザーデータおよび打刻記録は、Google Apps Script環境および利用企業の管理する（または当方が管理する）Googleスプレッドシート（Googleドライブ）上で保管・管理されます。不正アクセスや漏洩等を防止するための適切なセキュリティ対策を講じています。

5. データの保持期間と削除・アクセス解除の方法

ユーザーデータおよび勤怠記録は、サービス提供契約の存続期間中、および業務上必要な期間のみ保持されます。契約終了時や個別のご要望に応じたデータの削除、およびGoogleアカウントの認可解除（セキュリティ設定からのアクセス権削除）については、下記のお問い合わせ窓口までご連絡いただければ迅速に対応いたします。

6. ウェブサイトのアクセス解析について

当サイトでは、サイトの利用状況を把握し、サービス改善を行うために、Google LLCが提供するアクセス解析ツール「Googleアナリティクス4（GA4）」を利用しています。

Googleアナリティクスは、Cookie等を使用してユーザーの閲覧ページ、アクセス日時、利用端末・ブラウザ等の情報を収集・処理します。詳細については、Googleプライバシーポリシーと規約をご確認ください。また、ブラウザの設定やGoogleアナリティクス オプトアウト アドオンを利用することで、データ収集の無効化が可能です。

7. プライバシーポリシーの改定について

本プライバシーポリシーの内容は、法令の改正やサービス内容の変更等に伴い、改定されることがあります。重要な変更がある場合は、当サイト上において適切にお知らせします。

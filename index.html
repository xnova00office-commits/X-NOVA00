プライバシーポリシー（個人情報保護方針）

X-NOVA00（以下、「当方」）は、提供するサービス（以下、「本サービス」）におけるユーザーの個人情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 取得する情報

本サービスでは、機能提供のために以下の情報を取得・利用する場合があります。

  • ユーザー識別子（LINE等のユーザーID）
  • 本サービスの利用に必要な勤怠データ・入力テキストデータ
  • Googleアカウント等の認証に伴い取得する最低限のプロファイル情報

2. データの利用目的

  • 本サービスの円滑な提供、維持、改善のため
  • ユーザー認証およびデータ連携処理のため
  • お問い合わせ対応のため

3. 外部サービス（Google API等）の利用について

本サービスがGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（制限付き使用要件を含む）に準拠します。

4. 第三者への開示・提供

当方は、法令に基づく場合を除き、ユーザーの同意を得ることなく第三者に個人情報を提供することはありません。
